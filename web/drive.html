Server backups

                        
Point-in-time recovery archives for this complete Drive server.

                      

                      

                        
                        
                      

                    

                    

                      What a backup contains
                      
Each archive contains the server database and stored file content for every workspace. It is operator-readable and remains on this host until you download or copy it elsewhere. Drive does not track whether an off-host copy exists.

Sign-in protection

                        
Temporary blocks and failed-attempt counters for account sign-ins, 2FA, password changes, and protected guest links.

                      

                      

                        
                      

                    

                    

                      How this works
                      
Repeated failures can temporarily block an account or protected guest link for one browser or app. Drive stores a privacy-safe reference instead of another copy of its IP address. Remove a block only when you know the attempts are legitimate.
