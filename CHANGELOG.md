# Changelog

## 0.1.14

- Multiple independent desktop server connections, including distinct accounts
  on the same server, with a dedicated local folder for each connection.
- App preferences before setup, guided server/account/folder onboarding, and
  scoped editing, sign-in renewal, folder replacement, and removal that retain
  local files.
- App-wide and per-connection sync check intervals, clickable folder paths,
  and a combined History tab with filters, search, and paging.
- Direct **Download and install** for signed desktop updates in App settings.
- Existing desktop connections retain their folders, history, pause state,
  preferences, and remote-agent enrollment when upgrading.
